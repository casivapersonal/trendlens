Put NSE CSV files here (download them by hand from nseindia.com; any file name ending in .csv works).
  1. ASM list:  nseindia.com/reports/asm  -> "Long Term" tab -> Download (.csv), then "Short Term" tab -> Download (.csv)
               name them e.g. asm_long.csv and asm_short.csv
  2. GSM list:  nseindia.com/reports/gsm  -> Download (.csv)  -> name it gsm.csv
  3. Results:   nseindia.com/companies-listing/corporate-filings-board-meetings  -> Download (.csv)  -> e.g. board_meetings.csv
Effect: no new entry alerts for stocks on ASM/GSM; warnings and card badges for live ideas on ASM/GSM
or with quarterly results in the next 7 days. Refresh these files once a week (replace the old ones).
